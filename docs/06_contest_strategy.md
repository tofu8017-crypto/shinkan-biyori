# 06. コンテスト戦略（HOOT / 約1ヶ月）

## 1. 前提（FJさん共有事項・2026-06-03時点）

- **締切: 約1ヶ月後**（≒ 2026年7月初旬）。
- **課題オーナー: 非公開**（個人的なご縁のため、本ファイル・リポジトリ・デモ動画・note等いずれにも氏名・関係性を一切記載しない）。提起された課題は **「文芸（本）の情報が散らばっている」**。
  - 公開物では、この課題は **「一読者として感じる実在の不便」** として提示する（特定個人に帰属させない）。
- **提出物: リポジトリ ＋ デモ動画**。
- **目標に「1円以上マネタイズ」**を含む。
- **審査軸**: ① 自律性（人手を減らして価値提供）② 事業性（誰の課題を解決し、払う理由があるか）③ 売上につながる反応。
- ※ HOOTコンテストの一般公開情報は確認できず（クローズド企画と推定）。本計画はFJさん共有の前提に基づく。

## 2. ポジショニング（差別化1文）

> 各社・各店にバラバラな文芸の新刊情報を、**AIが毎日横断収集して「今日の一冊」を選書・紹介する、人手ゼロの自律編集メディア**。

- 「網羅」だけでは大手（ブクログ・honto・急急如律令）と被る＆Googleも評価しない。
- 価値の核は **集約 ＋ 選書 ＋ オリジナルの語り ＋ 自律運用**。

## 3. 審査軸への当てこみ

| 審査軸 | この企画での見せ方 |
|---|---|
| ① 自律性 | 収集→選書→紹介文生成→SNS下書き→公開を**無人で回す**（承認ゲートのみ人間）。デモ動画の主役 |
| ② 事業性 | 実課題「散らばる文芸情報」を解決。短期収益＝KU登録＋アフィリ、**拡張＝出版社/作家向けB2B（新刊の発見支援）** |
| ③ 売上反応 | 自分の導線（note・SNS・Kindle本読者）で実トラフィックを作り、**¥1+の成果を証拠化** |

## 4. 4週間プラン

### W1 基盤
- ブランド確定（[05](05_open_questions.md) Q1）＋ドメイン取得（取得OK方針）。
- Next.js + Supabase + Vercel 雛形（コーディが生成）。
- 楽天ブックスAPI＋openBDで「今日の文芸新刊」取得バッチ → GitHub Actions 日次（1秒1リクエスト遵守）。
- 一覧・書籍詳細・カレンダー（月表示＋日別バッジ）。

### W2 自律キュレーション層（★審査の主役）
- AIエージェントが毎日「今日の一冊」を選書＋**オリジナル紹介文**を生成（あらすじ転載NG→要約＋出典）。**人間の承認ゲート**付き。
- 各詳細ページに必ずオリジナルの一言を載せる（R3=アグリゲーション評価対策）。
- **KU（Kindle Unlimited）対象フラグ**＋「読み放題で読める新刊」導線。
- 楽天アフィリエイト（即）＋ もしもアフィリエイト経由Amazon（申請）。

### W3 集客＆売上実証
- note記事を数本公開（例:「散らばる文芸情報を一か所にしてみた」「今週の注目文芸新刊」）→ サイトへ導線。
- Instagram・X・Kindle本読者へ告知 → 実トラフィック。
- **¥1+の成果を計測しスクショで証拠化**（楽天/もしも/KU）。
- SNS下書き自動生成（承認キュー）を稼働＝自律性の見せ場。

### W4 仕上げ＆提出
- **デモ動画 3〜5分**（構成は §6）。
- README・再現手順・アーキテクチャ図・自律フロー図。
- 事業性の語り（課題→解決→収益→拡張B2B）。

## 5. スコープ（1ヶ月で勝つための線引き）

**今回入れる（IN）**: 楽天API取得／openBD補完／日次バッチ／一覧・詳細・カレンダー／「今日の一冊」AI選書＋紹介文（承認付き）／KU導線／楽天アフィリ／note数本／デモ動画。

**今回入れない（OUT＝コンテスト後）**: 大規模プログラマティックSEO（著者/出版社/月別の自動量産）／KPIダッシュボード／フル半自動SNSパイプライン／PA-API／その他購入先（Kobo/honto）。
→ 欲張ると全部が中途半端になる。**自律性が伝わる最小構成＋¥1実証**に集中。

## 6. デモ動画の構成（3〜5分）

1. 課題（「文芸情報が散らばっている」という読者の不便）— 30秒
2. 解決概要（横断収集＋毎日キュレーション）— 30秒
3. **自律の実演**（エージェントが収集→選書→紹介文→SNS下書きを無人で回す画面）— 90秒 ★主役
4. 成果（実トラフィック＋¥Xのマネタイズ証拠）— 45秒
5. 事業性・拡張（KU/アフィリ→将来B2B：出版社・作家）— 30秒

## 7. ¥1マネタイズ計画（最速順）

1. **KU登録（約¥500/件・目安）**＝本命。「この新刊、Kindle Unlimitedで今日から読める」導線で読者が登録 → 1件で目標達成。
2. 楽天アフィリエイト（クリック後の買い物全般が成果になりやすい）。
3. もしも経由Amazon（提携できれば）。
- ⚠️ **FJさん自身の購入・登録はカウント外**。読者に踏んでもらうこと。

## 8. リスク受容表

| リスク | 確率 | 影響 | 対策／受容 |
|---|---|---|---|
| SEOが1ヶ月で効かず無流入 | 高 | 軽微(コンテスト的に) | 受容。集客は自前導線。SEOは長期の伸びしろとして語る |
| 自律エージェントの運用費(6/15課金) | 中 | 軽微 | デモ規模は微小。Haiku/API従量で管理 |
| 読者が動かず¥1未達 | 中 | 痛い | KU強導線＋複数チャネル。FJさんの告知力が鍵 |
| 1ヶ月で作り切れない | 中 | 致命的 | スコープ厳守(§5)。MVP最小化 |
| アグリゲーション扱いで低評価 | 中 | 痛い | 各ページにオリジナル選書文（§W2）|

## 10. デザイン方針（2026-06-03 / FJさん指定）

- ターゲット: **30〜40代女性**。トーン: **ゆるふわ・淡い系**（スタイリッシュ/シャープ系ではない）。
- 配色: 生成り/オフホワイト基調＋くすみパステル（ミルクティーベージュ、セージグリーン、くすみローズ/ラベンダー）。彩度低め。
- 文字色は真っ黒を避け 墨色〜ダークブラウン。**ただし淡くしすぎず本文の可読性（コントラスト）は確保**（a11y／離脱防止）。
- 書体: 見出し＝明朝（文芸の上品さ）／本文＝丸み系ゴシック（やさしさ）。
- 形: 角丸大きめ・余白広め・細い線・手描き風の小装飾。書影を主役に。
- ムード: 「本屋さんのカフェ」「やわらかい自然光」「紙の質感」。
- 作り方: **lp-system スキル**でデザインシステム（パレット/タイポ/コンポーネント/ワイヤー）を生成 → そのまま Next.js（Tailwind）で実装。1ヶ月コンテストなので作り込みすぎず "on-brand × good enough × 速い"。**最終的な"可愛い"の承認はFJさんが行う**。
