# 07. コンテンツブログ（はてなブログ）— 読書記事の自律パイプライン v2

最終更新: 2026-06-03
位置づけ: 新刊日和の集客・ファン化チャネル。元の「ツボツボ実装パイプライン」を、**被リンク目的 → 読者価値＋自然な流入** に作り替えた健全版。

## 1. 設計思想（ここが変更点）

- ❌ 旧: 「被リンク対策のため」にAI記事を量産 → 自作自演リンク＝Googleガイドライン違反（SpamBrainで検出・最悪は **新刊日和ごとペナルティ**）。
- ✅ 新: **「読者に役立つ読書コンテンツのため」**。被リンクは“良い記事の自然な結果”に留める。狙いは ①読者価値 ②新刊日和への自然な流入（referral＝¥1マネタイズに直結）③ブランド・ファン化。
- **不自然なリンクは作らない。** リンクは文脈上ほんとうに役立つ時だけ・控えめ・自然なアンカーテキストで。

## 2. パイプライン v2（1本の記事が公開されるまで）

| Step | 内容 | ツール | 旧からの変更 |
|---|---|---|---|

## 3. ガードレール（健全さ＝サイトを守る）

- 被リンクを目的にしない。リンクは自然・控えめ・文脈依存。
- **質優先・少なく濃く**（Helpful Contentはサイト単位評価。薄いAI記事が積もるとブログごと沈む）。
- people-first / E-E-A-T：一次情報・独自視点・実際の読書体験。
- AIまる出しの薄い記事を出さない。編集者の声は一貫させ、透明性を保つ。
- 無人の `claude -p` は使わず **API従量（Haiku/Sonnet）＋人間承認**（2026-06-15の課金変更対策）。
- はてな規約・著作権（書影・引用）を守る。

## 4. コンテストでの位置づけ

- これは「**自律編集コンテンツエンジン**」＝ ①自律性のデモ素材 ②新刊日和への流入装置（売上反応に貢献）。
- 発表では「被リンク」の語を使わず「**読者に役立つ読書記事を自律生成し、人が承認して公開する**」と表現。
- ⚠️ SEOは1ヶ月では効かない。コンテスト期間の価値は「**SNS/はてな経由のreferral流入**」。被リンクの恩恵は長期のおまけ。
