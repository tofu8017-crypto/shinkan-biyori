| 用途 | フォント | 備考 |

## 余白（8px基準）

`4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 80 / 96px`

- カード内パディング: `16px`
- カード間ギャップ: `16px`（モバイル）/ `24px`（デスクトップ）
- セクション間: `48px`（モバイル）/ `64px`（デスクトップ）

## 書籍カード

```
┌─────────────────┐
│                 │  ← 書影（aspect-ratio: 3/4）
│    書影エリア    │     角丸12px
└─────────────────┘
 書名（Noto Serif JP / 2行まで）
 著者名（13px / text-muted）
 [楽天で買う] [Amazonで買う]
```

- 角丸: `12px`
- シャドウ: `0 2px 8px rgba(0,0,0,0.06)`
- ホバー: `translateY(-2px)` + シャドウ強め

## ジャンル

楽天ブックスAPIのジャンルコードに完全準拠。表示名は変更可能。

| 表示名 | 楽天ジャンルID |
|---|---|
| 小説（日本） | `001004008` |
| 小説（海外） | `001004009` |
| ミステリー | `001004001` |
| SF・ホラー | `001004002` |
| エッセイ | `001004003` |

> ジャンル追加時はこのテーブルに1行追加するだけ。変更があれば随時更新。

### ジャンルカラー（カード上部ボーダー）
- 小説（日本）: `#B8D4C4`（セージグリーン）
- 小説（海外）: `#D4C8B8`（ベージュ）
- ミステリー: `#C8B8D4`（くすみラベンダー）
- SF・ホラー: `#B8C8D4`（くすみブルー）
- エッセイ: `#E8C4B8`（くすみローズ）

### 猫キャラ（スロット確保済み・素材待ち）
- 各ジャンルカードの `64×64px` 丸枠に入る
- タブ型ナビの `28×28px` 丸枠にも入る
- 素材が届いたら `/public/cats/` に配置して差し替えるだけ
