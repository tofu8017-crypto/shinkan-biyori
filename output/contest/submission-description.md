# 新刊日和 — 人手ゼロの自律編集メディア（提出説明文）

## 一言で
文芸書の新刊情報を、AIが毎日「収集 → 執筆 → 公開 → 拡散 → 改善」まで無人で回す自律メディアです。さらに外部から被リンクを獲得する“もう1つの無人ループ”で、集客の土台（ドメインパワー）も自動で底上げします。

## 解く課題
文芸（本）の新刊情報は各社・各書店にバラバラで、一読者として「今日なにが出たか」を一望できません。その不便を、選書と編集者の語りを添えた自律メディアで解きます。

## 2つの無人ループ
1. **コラム自動公開ループ** — 毎日0:30に楽天API／openBDで新刊を収集し、DeepSeekで選書コラムを生成。品質ゲートを通った1本を翌朝6:00に公開し、IndexNow通知とX投稿原稿のDiscord配信まで自動で行います。
2. **被リンク獲得ループ** — 毎朝8:00、編集者ペルソナ「ナカノ」が読んで役立つ独自記事をはてなブログに自動投稿し、本文から新刊日和へ自然な dofollow リンクを張ります。リンク目的の薄い記事は逆効果なので、記事の質を最優先にしています。

人の関与は「前日ドラフトの確認」と「X原稿のコピペ投稿」だけ＝1日10分未満です。

## 暴走させない安全装置
1日1本ガード／生成翌日の遅延公開／機械品質ゲート（字数・キーワード・リンク・禁止語・重複）／被リンク本文のリンク実在(200)確認／AI臭チェック／成人・ラノベ等の除外フィルタ／事実は要約のみで原文転載・捏造は禁止。

## 審査軸への当てこみ
- **自律性**：無人の編集ループが2系統、毎日自動で稼働。人間は承認ゲートのみ。
- **事業性**：楽天／Amazonのアフィリエイト導線とクリック計測に加え、被リンクで集客の土台を底上げ。将来は出版社・作家向けのB2Bへ。
- **反応**：IndexNow＋X半自動キット＋Discord配信で初動を作り、`/stats` ダッシュボードで可視化。

## 実績
コラムは毎日自動公開で2万を超えるページを運用中。被リンク記事も初稿を実際に公開済みで、本文内リンクの dofollow を確認＝外部ドメインからの被リンク獲得を開始しています。
